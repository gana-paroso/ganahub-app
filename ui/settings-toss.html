전역 설정

공유폴더 인증, IDE 실행파일, 업무 포털 연동을 이 PC에 설정해요.

공유폴더 연결 설정

개발팀 공용 프로젝트 정보가 저장된 NAS 공유폴더 접속정보예요.

비밀번호는 Windows DPAPI로 암호화되어 이 PC에만 저장되며, 공유폴더에는 절대 저장되지 않아요.
IDE 설정

Eclipse, VSCode 등 실행 파일을 등록하면 IDE 관리에서 이름으로 골라 쓸 수 있어요.

DB 관리 설정

DB 관리의 ‘생성 / 권한 부여’에서 접근 허용 IP 기본값으로 채워져요. 이 PC에만 저장돼요.

업무 포털 연동

간편접수에 쓰는 업무 포털(/works) 서버 정보예요.

연동 규격업무 포털의 접수 규격(주소 형식, 헤더, 필드 이름)이에요. 이 PC에만 저장되고 소스 저장소에는 들어 있지 않아요.
공용 키는 Windows DPAPI로 암호화되어 이 PC에만 저장돼요.
